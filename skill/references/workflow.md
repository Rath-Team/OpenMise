# 共同执行约定

## 能力与状态

技能说明不会安装或注册 Blender 工具。先确认宿主实际提供的场景查询、Python 执行、
渲染、图像读取和文件能力；可用 Blender MCP 或其他受控的 Blender 执行方式。
仅靠文本对话无法直接操作 Blender。缺少能力时指出具体缺项，不编造工具结果。

编辑前检查场景、活动相机、当前帧、单位和资产层级，保存工作副本。
增量导入与修改只影响任务相关对象；新场景可在独立进程创建。
生成的 Python 以本机进程权限执行，执行前确认源码和目标路径属于当前任务。
只按实际任务需要安装依赖、调用外部服务或下载资源。

## 物理与坐标

区分局部/世界坐标、米/场景单位、角度/弧度以及帧编号约定。
资产统一变换在根对象上完成；骨架和蒙皮不能独立错位。
方向、尺度、支撑、语义位置和可达性分别建立证据。
人物尺寸与镜头取景独立检查，不为绕过净空失败改变角色大小。

## 迭代与验收

先渲染关键预览，实际查看画面，再进行完整输出。采样包含首尾、动作边界、
接触/释放、转角、切镜和遮挡变化处；快速变化区间增加采样。
数值测量、图像判断与输出文件有效性各自留存依据。
修改源码、资产、动画、相机或渲染设置后，重做受影响的检查。
没有看图能力时说明待视觉检查，不自动标记通过。

保留可恢复工程和必要的修正记录；设定与任务相称的重试上限。
超时先查询状态，不重复提交仍在执行的操作。
报告真实产物路径、已检查项目、已知问题及未验证范围。
运行输出与用户素材保存在工作目录，技能目录仅保存可分发内容。
