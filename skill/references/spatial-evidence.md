# 扫描场景的空间证据

以下是推荐的工作记录，不是工具调用协议。由宿主工具保存与更新。

| 事实 | 至少记录什么 | 不能据此推断什么 |
|---|---|---|
| 观察 | 图像路径、相机矩阵、图像尺寸、帧、资产姿态、覆盖区域 | 未被看到的区域是否存在目标 |
| 方向 | 地面/天花板/天空线索、几何或模型估计、冲突与不确定性 | 北向、真实比例 |
| 支撑 | 局部视图、平面位置/法线、适用范围、验证依据 | 全场景存在同一无限平面 |
| 尺度 | 已知长度、对应测量、单位、误差、measured/estimated/unknown | 人物与门洞必然可通过 |
| 语义锚点 | 名称、世界位置/区域、视图或用户确认依据 | 二维检测直接等同三维实体 |
| 可达性 | 可走区域、障碍、门洞连接、角色净空及未知区域 | 楼梯/多层/全身动态碰撞通过 |

所有位置与区域绑定到同一资产变换和世界坐标。记录扫描文件身份、根矩阵和单位；
扫描姿态改变后更新相关地图，不能沿用过期锚点。

几何候选平面不是已确认地面；最大平面可能是墙。粗代理网格和高斯中心只提供近似信息。
支撑需要局部斜视图，门洞需要两侧和通路视图；远距离总览不足时继续采集有用观察。
不能通过隐藏真实障碍或创建虚构地面使计划通过。

没有尺度依据可以继续视觉识别，但不能声称米制放置或通行净空可靠。
记录未知比填入未经验证的坐标更有用。放置与路线检查通过后仍需实际渲染验收。
