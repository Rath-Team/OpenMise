# 复杂场景生成与修正

用于现有基础动作不足以表达的交互、机械运动或多角色短片。
由宿主 Agent 编写完整 Blender Python，使用用户已配置的执行工具；本技能不提供后台监督服务。

1. 从需求提取可观察的验收项：对象身份、时序、运动、接触、释放、镜头与交付物。
2. 新建独立工作目录，记录需求、源码版本、帧率和时间范围。为新场景使用独立 Blender 进程；
   现有工程的编辑先另存副本。执行源码具有本机用户权限。
3. 用 `bpy` 建立几何、材质、骨架、关键帧与相机；需要模拟时烘焙结果。
   `.blend` 不会自动保存临时 Python 回调的执行环境。
4. 在动作开始/结束、抓取/交接、释放及中间状态渲染预览。
   数值检查覆盖距离、位置连续性和相对运动；包围盒在画面内不证明没有遮挡。
5. 实际查看图片，记录穿插、悬空、身份跳变、接触和取景问题，并修正对应源码。
   不以存在性检查替代交互验收，不改变验收条件掩盖失败。
6. 按任务规模设定有限修正次数。重复同类失败时改变实现策略；达到上限后交付现状与未解决项。
7. 从通过检查的同一工程渲染，复核最终视频关键帧、尺寸、时长与帧数。

没有真实看图能力时保留“待视觉检查”状态；不能宣称完整验收。
新源码、相机或场景改变会使相关旧预览失效。

操作前遵循[共同执行约定](../references/workflow.md)，只使用当前宿主实际可用的工具。
