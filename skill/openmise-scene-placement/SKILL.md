# 人物与资产摆放

先确认场景尺度、目标区域和局部支撑；仅有方向校正或二维检测框还不足以定位人物。
使用[空间证据](../references/spatial-evidence.md)记录依据。

1. 检查当前扫描变换与空间数据一致，并选择已确认的地面或支撑面。
2. 根据世界尺度换算角色尺寸，计算脚底/接触参考点，而非把资产原点默认当作脚底。
3. 变换资产根对象，保留骨架与蒙皮层级；设置朝向时核对角色实际前方轴。
4. 用真实视图检查脚底接触、悬空、穿插、相对尺寸和目标语义位置。
5. 粗网格代理可辅助净空判断，但需注明近似程度。高斯中心不自动代表实物表面。
6. 相机看不清角色时调整构图。不要缩小人物来掩盖门洞过窄或净空失败。

未确认的支撑/尺度应明确标记；不能凭空补一块水平地面当作真实扫描结构。

操作前遵循[共同执行约定](../references/workflow.md)，只使用当前宿主实际可用的工具。
