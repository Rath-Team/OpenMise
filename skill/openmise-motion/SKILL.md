# 姿态与程序化动作

先检查目标骨架、静止姿态、关节轴与控制方式。避免同时以 FK、IK 和根对象关键帧争夺同一自由度。

1. 用时间轴明确站立、行走、转身、指向、伸手、下蹲等动作的开始、结束与保持阶段。
2. 分开处理根位移与肢体步态；转向时同步脚步与身体朝向，检查滑步。
3. 伸手或抓取检查臂展、手部接触、物体相对变换和释放连续性。
   标记点接近不能单独证明手指抓握、网格接触或无穿插。
4. 使用合适插值与切线，避免转身跨角度突跳。约束切换应保持世界变换连续。
5. 检查脚底支撑、关节翻转、骨长和关节范围；相邻动作之间保留连续姿态。
6. 保存或烘焙最终动画，查看动作边界和快速运动区间，再交付工程。

复杂舞蹈优先使用有授权的动作文件并做显式兼容检查，见[动作导入](../openmise-motion-import/SKILL.md)。

操作前遵循[共同执行约定](../references/workflow.md)，只使用当前宿主实际可用的工具。
