# 相机管理与构图

用于创建、删除、变换与静态取景；连续镜头运动另见相机运动主题。

1. 检查已有相机、活动相机和用户希望保留的镜头。
2. 新建相机并赋予唯一名称，明确透视/正交投影、位置、朝向和裁剪范围。
   Blender 相机局部 -Z 为前方、+Y 为上方。
3. 结合主体世界范围、画幅和焦距设置取景，检查实际活动相机而非仅看编辑视口。
4. 查看渲染预览确认主体大小、边缘裁切、遮挡和前后景关系。
5. 修改镜头或切换活动相机后重新取预览；删除时保持明确的可用活动相机。

包围盒落在画幅内不能证明主体无遮挡。正交投影与长焦透视具有不同空间效果。

操作前遵循[共同执行约定](../references/workflow.md)，只使用当前宿主实际可用的工具。
