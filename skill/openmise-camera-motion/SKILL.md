# 跟拍与运动镜头

将自然语言镜头拆成时间段、目标、空间路径、焦距和切镜规则。

1. 先确定人物真实运动，再规划相机。跟随偏移明确使用世界坐标还是角色局部坐标。
2. 跟拍检查距离和高度；环绕明确中心、半径与角度；推拉改变位置，变焦改变焦距。
3. 用约束或关键帧保持朝向，避免目标与相机重合导致方向奇异，检查 roll 突跳。
4. 每段定义起止帧、插值和主体在画面中的位置，切镜不改变人物的物理轨迹。
5. 检查路径与墙体/家具的交叉，并在关键帧之间检查遮挡、穿墙和主体出画。
6. 实际预览首尾、转折、快速运动和切镜附近，修改后重新验证相关区间。

空间地图中的可走区域不自动代表相机可飞行区域。
数值距离与构图检查分别记录，不用有效路径代替视觉验收。

操作前遵循[共同执行约定](../references/workflow.md)，只使用当前宿主实际可用的工具。
