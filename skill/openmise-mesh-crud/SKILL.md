# 网格管理

适用于 OBJ 等静态网格管理与纹理修复；人物骨架导入使用人物导入主题。

1. 记录导入前对象集合、选择、活动对象与相机，确认文件及引用纹理存在。
2. 通过当前 Blender 版本可用的导入操作增量导入；不要为导入一个物体清空整个场景。
3. 用导入前后对象差集识别本次资产，建立共同根对象，检查世界包围盒、单位和材质槽。
4. 在根对象上统一缩放、旋转、平移；区分局部与世界坐标。包含负缩放时检查法线。
5. 缺失纹理按原有相对目录定位；保留透明度、颜色空间与法线贴图语义。
6. 删除时使用准确对象身份和依赖关系，只删除指定资产；共享材质/贴图不要随意清理。

用真实预览核对尺度、方向、法线、纹理和透明度。对象成功导入不代表外观已正确。

操作前遵循[共同执行约定](../references/workflow.md)，只使用当前宿主实际可用的工具。
