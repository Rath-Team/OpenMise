# 程序化人物生成

用于镜头预演与简单动作，不承诺写实人物、自动高质量蒙皮或复杂服饰物理。

1. 明确角色高度、体型与风格；新建米制场景可用普通成人比例作为可修改默认值。
   现有扫描的尺度必须单独确认。
2. 创建根对象与身体分段，保持关节位置、肢段长度和左右命名一致。
3. 需要骨架时建立清晰父子链，绑定几何并检查静止姿态。
4. 按动作需要添加 IK，记录链长度、目标和 pole；伸手目标超出臂展时调整动作或位置，
   不把求解器截断的末端视作已经接触目标。
5. 用站立、屈膝、转身与抬手预览检查骨长、左右方向和关节翻转。
6. 记录朝向轴与脚底参考点，再进入场景摆放和动作工作流。

角色几何、骨架与控制器应归属于同一资产根，便于统一变换和清理。

操作前遵循[共同执行约定](../references/workflow.md)，只使用当前宿主实际可用的工具。
