# 动作导入与重定向

已有动作使用 BVH、FBX、glTF、`.blend` 或兼容 MMD 工具支持的 VMD。
目录输入先列出文件，选择具体动作，不把文件名当作内容或兼容性证明。

1. 检查源文件、帧率、帧范围、根运动、骨架与轨道类型。
2. 明确目标人物与骨架；导入源动画不得覆盖无关人物或清空场景。
3. 同骨架检查名称、静止姿态与单位；跨骨架建立显式骨骼映射、轴向转换与根运动策略。
4. VMD 应使用兼容的 MMD Tools 并检查日文骨名、形态键、IK 开关与显示轨道。
   报告未匹配项，不把部分成功视作完整兼容；相机/灯光轨道需要单独检查是否支持。
5. 设置起始帧、速度和循环时说明时间换算，避免不经确认重复应用根位移。
6. 检查脚滑、关节翻转、表情、根高度与场景接触，必要时烘焙到目标骨架。

动作导入不自动提供衣服/头发物理或配乐。保留原文件和授权说明，
交付时说明已导入的轨道与缺失内容。

操作前遵循[共同执行约定](../references/workflow.md)，只使用当前宿主实际可用的工具。
