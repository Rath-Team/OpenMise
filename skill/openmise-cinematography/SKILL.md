# 镜头语言与景深

根据叙事目的选择全景、中景、特写及视角，再设置具体相机参数。

1. 明确画幅、主体、镜头距离和希望保留的空间关系。
2. 透视相机联合调整焦距与距离；改变焦距不等于移动机位，不能混淆变焦与推轨。
3. 正交相机适合无透视缩放的示意效果，以正交尺度控制画幅。
4. 景深先确定对焦对象/距离，再设置光圈。检查最近/最远主体是否仍可辨认。
5. 检查裁剪面、镜头穿墙、背景遮挡与画面连续性。
6. 在最终渲染器中实际预览焦点和散景；视口效果不能代替成片检查。

不通过改变人物物理尺寸修复构图。含运动时使用[相机运动](../openmise-camera-motion/SKILL.md)。

操作前遵循[共同执行约定](../references/workflow.md)，只使用当前宿主实际可用的工具。
