# 自然语言布光

把“柔和日光”“轮廓光”“夜景”等描述拆成方向、色温/颜色、对比、阴影软硬和环境亮度。

1. 检查渲染器、世界节点、曝光和色彩管理，记录基准预览。
2. 按需设计主光、补光和轮廓光；先解决主要可读性，再增加灯数。
3. HDRI 来自用户有权使用的文件，检查路径、旋转、强度和世界节点连接。
4. 分开调整灯能量、面积、材质和曝光，避免用曝光掩盖错误的光照关系。
5. 3DGS 外观可能已含采集时照明；普通灯光不保证像网格一样重新照亮高斯。
   混合场景需分别检查角色照明与扫描背景是否协调。
6. 实际渲染确认阴影方向、肤色/材质、噪点与高光；动画布光检查关键时段的一致性。

材质、渲染器或环境变化会影响结论，应重新检查实际画面。

操作前遵循[共同执行约定](../references/workflow.md)，只使用当前宿主实际可用的工具。
