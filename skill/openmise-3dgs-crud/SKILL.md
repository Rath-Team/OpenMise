# 3DGS 资产管理

先完成 3DGS 组件配置。检查 PLY 头部与属性，区分普通点云和包含高斯尺度、旋转、透明度及颜色信息的资产。
不因文件扩展名为 `.ply` 就假定它可用作 3DGS。

1. 使用兼容的高斯导入器，记录导入资产根对象和原始变换，保留已有工程。
2. 检查高斯数量、边界范围及渲染缓存；先用低分辨率真实渲染确认可见性。
3. 用根对象变换管理位置/朝向/尺度，确认插件实际更新完整高斯，而非仅移动中心点。
4. 执行方向校正前使用[方向与识别](../blender-3dgs/SKILL.md)，保留可恢复的原始矩阵。
5. 删除指定扫描时一并核对其代理和缓存，避免误删其他资产。

高斯表示没有自动提供可行走地面、封闭网格或真实碰撞体。
扫描与人物混合渲染时必须实际检查二者的遮挡、阴影和尺度关系。

操作前遵循[共同执行约定](../references/workflow.md)，只使用当前宿主实际可用的工具。
